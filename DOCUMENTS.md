# Document checklist

Every file the app links to, grouped by folder (99 files). Folder and file names must match exactly, including upper/lower case and spaces, or the link in the app will not open.

Run `make-folders.ps1` to create the folders and see which files are still missing.

Three more Rico folders are named in the app but no document uses them yet: `Rico/ED-Cable`, `Rico/FW100CT.2`, `Rico/Vertica 40`. The script creates them. An `SR50…` folder is mentioned too, but its full name isn't recorded.
